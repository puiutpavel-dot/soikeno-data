# soikeno-data

Rezultate Vietlott Keno (20/80) pentru aplicația SoiKeno, actualizate automat de GitHub Actions.

- `data/keno.jsonl` – toate extragerile (format identic cu vietvudanh/vietlott-data)
- `data/keno-latest.jsonl` – ultimele 300 de extrageri (fișier mic, pentru aplicație)
- `data/status.json` – ultima extragere și ora actualizării

Surse: ketquaday.vn, baomoi.com, arhiva publică vietvudanh/vietlott-data. Proiect neafiliat cu Vietlott.
